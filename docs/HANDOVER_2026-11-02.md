## What needs the backend

Three settings stop the API from starting. Every other one switches a feature on, and a missing one
turns that feature off or leaves a placeholder instead of crashing (Razorpay, Cashfree and image
storage answer 503). The production API is up (`/v1/health` answers 200 on 2 Nov), but Railway,
Vercel, Firebase and the provider dashboards were not visible while this was written, so the status
column says what to confirm, not what is set.

### Railway: the API

The code is `backend/packages/config/src/env.ts`; its comments are the authority on each variable.

| Variable | What it does | If missing |
| --- | --- | --- |
| `FIREBASE_PROJECT_ID`, `GCP_PROJECT_ID` | Which Firebase project to use. Production is `galleryzone-prod` | The API does not start |
| `FIREBASE_SERVICE_ACCOUNT_JSON` (or `GOOGLE_APPLICATION_CREDENTIALS`) | The Admin SDK key, inline JSON on Railway. This is the real Firebase connection | The API cannot reach Firestore |
| `PAYMENTS_MODE` | `razorpay` for real payments. `simulated` lets a customer mark their own order paid | Unset in production, or a stale value such as `cashfree`, stops the API on purpose |
| `NODE_ENV`, `PORT` | `production`; Railway sets the port | Defaults to development |
| `CORS_ORIGINS` | Comma-separated browser origins. Must include `https://www.galleryzone.art` | Defaults to localhost |
| `PUBLIC_SITE_URL`, `PUBLIC_API_URL` | The website's address (payment return and email links) and the API's | Falls back to the first CORS origin, or the Railway domain |
| `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` | The gateway. The webhook secret is a third credential, chosen when the webhook is registered. Register the webhook on `gz-web-production.up.railway.app`: older docs name a host that is dead | Payment routes answer 503 |
| `CASHFREE_ENV`, `CASHFREE_VERIFICATION_APP_ID`, `CASHFREE_VERIFICATION_SECRET_KEY`, `CASHFREE_VERIFICATION_PUBLIC_KEY` | Aadhaar and GSTIN checks only (Cashfree Secure ID). `CASHFREE_ENV` defaults to `sandbox`; going live is deliberate. The public key is a PEM, or use IP allow-listing. Use the oldest client id on the account | Verification routes answer 503: this is why Aadhaar shows as unavailable |
| `SHIPROCKET_EMAIL`, `SHIPROCKET_PASSWORD`, `SHIPROCKET_WEBHOOK_SECRET`, `SHIPROCKET_BASE_URL`, `SHIPROCKET_PICKUP_LOCATION_NAME` | Live delivery quotes and shipments. The first three must be set together | No live quotes |
| `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_ENDPOINT`, `S3_REGION` | Object storage for artwork images and profile photos (a Railway bucket) | Image routes answer 503 |
| `RESEND_API_KEY`, `EMAIL_FROM`, `EMAIL_REPLY_TO` | Email. See [`EMAIL_GO_LIVE.md`](EMAIL_GO_LIVE.md). `EMAIL_REPLY_TO` is new in this branch | Emails are logged, not sent; the sandbox sender reaches only the Resend account owner |
| `MOU_SIGNATORY_NAME`, `MOU_SIGNATORY_DESIGNATION` | Who signs for GalleryZone on every MOU | Generic "GalleryZone Private Limited / Authorised Signatory" |
| `INVOICE_SELLER_LEGAL_NAME`, `_ADDRESS_LINE1`, `_ADDRESS_LINE2`, `_CITY`, `_STATE`, `_PINCODE`, `_GSTIN`, `_STATE_CODE`, `_CIN`, `_SUPPORT_EMAIL` | The seller on tax invoices. The code says production must set these | Placeholders ("GalleryZone Office", Bengaluru): not a valid tax invoice without a GSTIN |
| `SENTRY_DSN` | Error reporting | None |
| `NFC_REMINDER_SWEEP`, `HOLDING_EXPIRY_SWEEP` | Timers inside the API: NFC lock reminders hourly, placement expiry every 15 minutes. Set to `false` to turn one off | They run |

Never set `FIRESTORE_EMULATOR_HOST` or `FIREBASE_AUTH_EMULATOR_HOST` in production: they send the API to the local emulators.

## Run it locally

The whole product runs on your machine against Firebase emulators, filled with a believable data set:
10 artists, 5 aggregators at different points of their 30-day placement, 6 collectors, 55 artworks in
every state, orders, money, and the admin queues. It only talks to the emulators and refuses any
Firebase project not named `demo-*`, so production cannot be touched. The full guide is [`DEMO_DATA.md`](DEMO_DATA.md).

Needs Node 22.6 or newer (the scripts run with `--experimental-strip-types`) and Java for the Firestore
emulator. Three terminals, from `backend/` unless noted:

```bash
npm ci                                      # once
npm run demo:emulators                      # Firestore :8180 + Auth :9099, data kept in backend/.demo-data
npm run build                               # once, and after backend changes
node --env-file=demo.env --experimental-strip-types apps/api/dist/main.js     # API on :8080
npm run demo:seed                           # fill the emulator (first run only); demo:reseed redoes it, demo:clear wipes it
cd ../frontend-web && set -a && . ../backend/demo.env && set +a && npx next dev   # website on :3000
```

On PowerShell, load `backend/demo.env` into the session before `npx next dev`. Every account uses the
password `Demo@12345`: `admin@demo.galleryzone.art`, `artist1` to `artist10`, `aggregator1` to
`aggregator5` and `customer1` to `customer6`, all at `@demo.galleryzone.art`. These exist only in the
local emulator.

The phone app: `flutter run --dart-define=GZ_API_URL=http://10.0.2.2:8080` on an Android emulator. A
`GZ_AUTH_EMULATOR` define for the Auth emulator was written but never run on a device.

## How the code is laid out

GalleryZone is an Indian marketplace for original artwork. Every piece carries a verifiable identity
(artist, owner, history) through a QR code or NFC tag that opens a public passport at
`/verify/<artworkId>`. Artists list at a private price, aggregators (galleries) display pieces for 30
days, and collectors buy, own and resell. The company is GalleryZone Private Limited; the name is
GalleryZone, not ArtVault.

| Folder | What it is |
| --- | --- |
| `frontend-web/` | The website: Next.js 16, React 19, Tailwind v4. Deployed on Vercel |
| `backend/apps/api/` | The NestJS API on Railway. Controllers are thin and call the database functions |
| `backend/apps/jobs/` | An empty placeholder. Scheduled work runs as timers inside the API process (placement expiry, NFC reminders) |
| `backend/packages/domain/` | Pure logic with no I/O: the pricing engine, state machines for orders, holdings and artworks, ledger rules |
| `backend/packages/db/` | Every Firestore read and write. Security rules deny all client writes, so the API is the only writer |
| `backend/packages/contracts/` | Shared request shapes and the route registry (`api-routes.ts`) |
| `backend/packages/config/` | The typed environment and the versioned rate config |
| `mobile/` | The Flutter app (Riverpod) |
| `docs/` | Plans, audits, status and decisions. Several are out of date: see below |

Things that will trip you up:

- **Many rules are pinned by a check.** `npm run check` runs 68 steps (pricing, settlement, state machines, ledger, NFC, MOU, routes, emails). One of them, `check:client-routes`, fails if the website or app calls an API route that does not exist. Add a route to `api-routes.ts` when you add a controller route.
- **No rate or fee is a literal in code.** GST, markup, advances and commissions come from the versioned rate config. Do not change money rules without the owner.
- **Money is integer paise.** Format with the en-IN helpers.
- **Emails and pushes never fail a request.** Call them as `void this.emails.x(...).catch(this.emails.swallow("label"))`.
- **Windows line endings.** Working files are CRLF (`core.autocrlf=true`), so a multi-line text edit on an existing file can miss its anchor. Edit with a tool that keeps each file's own line endings.
- **Node's type stripping has limits.** The `*.check.ts` files run with `--experimental-strip-types`, which cannot load Nest decorators or constructor parameter properties. To exercise a Nest service from a script, import the compiled `apps/api/dist`. And `npm run build --workspace=@galleryzone/api` is the real type check of the API: `check:types` alone covers only the packages.
- **Flutter rewrites generated files.** After `flutter test` or `flutter analyze`, the plugin registrant files under `mobile/linux`, `macos` and `windows` show line-ending-only changes. Revert them before committing.
- **Playwright against one dev server times out.** Use `--workers=2 --project=chromium`. Pages stay loading skeletons unless the `NEXT_PUBLIC_FIREBASE_*` variables are set (placeholders are enough), and the onboarding tour covers portal pages unless `localStorage` has `gz_tour_completed_<role>`.
- **Old docs disagree with the code.** [`plan.md`](plan.md) ("ArtVault") is the original Postgres and Cloud Run plan, superseded by Firestore on Railway. [`NEXT_SESSION_PROMPT.md`](NEXT_SESSION_PROMPT.md) still says there is no backend. Older docs describe insurance as mandatory; it was removed on 24 Oct 2026. The payment gateway is Razorpay; Cashfree is only for Aadhaar and GSTIN checks.
- **The repo has secrets protection.** GitGuardian runs on pull requests. Keep every key in Railway or Vercel, never in a file.
