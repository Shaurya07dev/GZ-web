# Google Play submission package

This directory contains the text and disclosure drafts for package
`in.galleryzone.app`. It is a handoff, not evidence that an app was uploaded or
approved.

- Privacy policy: `https://www.galleryzone.art/privacy`
- Account-deletion page: `https://www.galleryzone.art/account-deletion`
- Support email: `galleryzone@zohomail.in`
- Default language: English (India)
- Category: Art & Design
- Monetisation: physical artwork sales through Razorpay and disclosed Amazon
  affiliate links; no digital goods or subscriptions are sold in the app.

`en-IN/` contains the store text. `DATA_SAFETY.md` is a Console-answering aid,
not a substitute for reviewing every production SDK and provider. Complete
`RELEASE_CHECKLIST.md` before creating a production release.

Graphics still have to be captured/exported from the approved brand and a real
release build:

- 512 x 512 PNG Play icon (the current 1024 x 1024 launcher source is in
  `assets/icon/app_icon.png`).
- 1024 x 500 feature graphic.
- At least two real phone screenshots, with checkout/KYC test data and no real
  personal or financial information visible.
